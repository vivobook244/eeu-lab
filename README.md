# EEU LAB

**Explore. Experiment. Understand.**

EEU LAB is an interactive physics laboratory focused on helping learners explore physics through scientifically grounded simulations.

## Technology

- Astro
- TypeScript (strict baseline)
- React islands (added in Phase 1.2)
- Tailwind CSS (added in Phase 1.4)

## Requirements

- Node.js 22.23.4 or newer
- npm

Use the repository-pinned Node version:

```bash
nvm use
```

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
